# تكامل Telegram/TDLib — الحالة والبوابة

الحالة: نُفّذ تكامل Telegram في Task 05 داخل TeleManager (`TelegramProvider` + الجسر الأصلي `TdlibBridge.kt` + `io.github.tdlib-android:core:0.1.1` — TDLib 1.8.67)، مع 51 اختبار وحدة/عقدة وCI أخضر (التشغيل 44841893201). ولم يُختبر نقل الملفات بعد (مهمة 06)؛ ولم تُختبر المصادقة على جهاز داخل التطبيق بعد (لا واجهة مصادقة). وهذه الوثيقة تحوّل قواعد المخطط إلى بوابة تقييم وتنفيذ.

## تقييم TDLib قبل التنفيذ
1. فحص وثائق TDLib الرسمية وواجهات API الحالية.
2. تقييم artifacts جاهزة موثوقة ومحدثة (Maven/JitPack عند الاقتضاء): provenance، الترخيص، الإصدار، ABI، توافق Android وسجل التحديث.
3. إن لم يتوفر artifact مناسب، توثيق build reproducible من المصدر: نسخة TDLib، NDK/CMake، build flags، ABI، المخرجات والتراخيص.
4. بناء مشروع Android تجريبي منفصل وإثبات إنشاء العميل، تدفق الحالة، استقبال التحديثات، الإلغاء/الأخطاء، وإدارة مسارات بياناته. ونقل الملف التجريبي لم يحدث في الـ Spike — فهو اختبار Task 06 (المرحلة 5 في `ROADMAP.md`)، لا شرطًا لبوابة TDLib/المصادقة.
5. لا تبدأ المصادقة/الرفع/التنزيل داخل TeleManager قبل توثيق نتيجة هذه البوابة.

## قرار معماري
حصر TDLib في `TelegramProvider` وطبقة Android الأصلية المحتملة. الواجهة لا تتعامل مع TDLib. لا تضع أسرار Telegram أو الجلسة في السجلات. خزّن جلسة TDLib ضمن مساحة التطبيق الخاصة، ووفّر خروجًا آمنًا.

## تدفق المصادقة المطلوب
رقم الهاتف → رمز التحقق → كلمة مرور Two-Step Verification عند طلبها → انتظار `authorizationStateReady` → حفظ الجلسة محليًا الآمن → استعادتها لاحقًا. لا تسجّل أي رمز أو كلمة مرور أو بيانات جلسة.

## قناة التخزين
بعد المصادقة، تحقق من وجود قناة مرتبطة بالحساب. اطلب موافقة واضحة قبل إنشاء قناة خاصة جديدة. لا تنشئ قناة عند كل تشغيل. خزّن مرجعها، تحقق من الصلاحيات، وأتح للمستخدم الاطلاع عليها وإدارتها وإعادة الربط. اشرح الفشل والقيود.

## التعامل مع الحدود والأخطاء
- لا تثبت الحد لكل حساب؛ اقرأ AccountCapabilities وحدود المزود الفعلية، والخادم يحسم الرفض.
- احترم مدة `FLOOD_WAIT` كما يحددها Telegram.
- لا تفترض وجود HTTP URL دائم.
- لا تعتبر `message_id` أو `file_id` وحده معرف TeleManager الدائم.
- أخطاء مطلوبة: FLOOD_WAIT، الشبكة، فشل الرفع، انتهاء المرجع، امتلاء المساحة، طلب المصادقة، تجاوز الحد، نقص الصلاحيات. استخدم backoff وحد محاولات مع حالة نهائية مفهومة.
- Telegram Cloud Chats ليست Secret Chats مشفرة طرفًا لطرف؛ وضّح ذلك للمستخدم.

## معيار الإكمال
لا تعتبر التكامل مكتملًا إلا باختبارات Android حقيقية/ملائمة تثبت المصادقة واستعادة الجلسة، التعامل مع 2FA، الرفع مع تقدم وتأكيد مرجع سحابي، التنزيل والتحقق، وأخطاء الشبكة والإلغاء، وفق قيود الحساب.

نتائج الاختبار حتى الآن: بوابة TDLib (Task 03) وQR/استعادة الجلسة (Task 04) مثبَتة على جهاز في الـ Spike المستقل (حساب اختبار)؛ وعقد المزود (Task 05) مثبَت باختبارات وحدة/عقدة بمحاكيات (51 اختبارًا) وCI أخضر — وهذه لا تثبت اتصال TDLib حقيقيًا. ولم تُختبر المصادقة داخل التطبيق على جهاز بعد، ولم يُختبر نقل الملفات بعد (Task 06).
